Overview

Abstract

Same-day changes in the federal funds target are a convenient but incomplete label for the hawkishness of FOMC communication. This report evaluates TypeSafe/Jev under a fixed pairwise Choice criterion on chair press-conference openings, with Bradley–Terry aggregation and pre-registered gates. Primary quantities include standard errors (STE) and bootstrap confidence intervals. Correlation with FedLock press-conference scores is reported as an external consistency check, not as a methodological replication.

Contributions

  1. Frozen three-stratum gold pairs with inversion and calibration diagnostics.
  2. Dual-order Choice protocol, BT ranks with fit uncertainty, and cost/latency artifacts.
  3. Pre-registered tests separating scheduled action days from holds.
  4. Explicit FedLock fidelity statement (agreement vs replication).
  5. Head-to-head Choice comparison with Claude Haiku 4.5 under matched pairs.
