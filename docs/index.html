Abstract

Same-day changes in the federal funds target are a convenient but incomplete label for the hawkishness of FOMC communication. This report evaluates TypeSafe/Jev under a fixed pairwise Choice criterion on chair press-conference openings, with Bradley–Terry aggregation and pre-registered gates. Primary quantities include standard errors (STE) and bootstrap confidence intervals. Gate 4 treats same-day funds-rate changes as an incomplete label for textual hawkishness under holds. Gate 7 reports correlation with FedLock press-conference scores as an external consistency check, not as a methodological replication. Experiments 3–7 hold gold labels fixed while varying the question interface.

Contributions

  1. Frozen three-stratum gold pairs with inversion and calibration diagnostics.
  2. Dual-order Choice protocol, BT ranks with fit uncertainty, and cost/latency artifacts.
  3. Pre-registered tests separating scheduled action days from holds.
  4. Explicit FedLock fidelity statement (agreement vs replication).
  5. Head-to-head Choice comparison with Claude Haiku 4.5 under matched pairs.
  6. Interface probes (Experiments 3–7): composite Scores, multi-label Nouls, paraphrase calibration, span Choice, macro-conditioned Choice.
